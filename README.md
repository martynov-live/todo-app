# ✅ Список задач

Красивый To-Do лист на русском языке с тёмным дизайном. Работает прямо в браузере — без серверов и установки.

🌐 **[Открыть приложение](https://martynov-live.github.io/todo-app/)**

## Возможности

- Добавление задач (поле ввода + Enter или кнопка)
- Отметка задач как выполненных
- Удаление отдельных задач
- Фильтрация: все / активные / выполненные
- Статистика и прогресс-бар
- Очистка всех выполненных задач одной кнопкой
- Задачи сохраняются в `localStorage` — не теряются при перезагрузке

## Технологии

- HTML5
- CSS3 (переменные, анимации, градиенты)
- Vanilla JavaScript

## Запуск

Откройте файл `index.html` в любом браузере — никаких зависимостей не требуется.
