# ☑️ Мои задачи

Минималистичный планировщик задач в стиле Notion на русском языке. Работает прямо в браузере — без серверов и установки.

🌐 **[Открыть приложение](https://martynov-live.github.io/todo-app/)**

## Возможности

### Управление задачами
- Добавление задач (поле ввода + Enter или кнопка)
- **Редактирование** задачи двойным кликом прямо в списке
- Отметка задач как выполненных
- Удаление отдельных задач и очистка всех выполненных разом
- **Drag & drop** — перетаскивание задач за ручку для изменения порядка

### Организация
- **Приоритеты**: высокий ↑ (красный), средний → (оранжевый), низкий ↓ (зелёный)
- **Теги**: произвольные метки, создание новых прямо из поп-апа
- **Дедлайны** с цветовой индикацией: просрочено (красный), сегодня (оранжевый), в будущем (серый)
- Цветная полоса слева у задач с истёкшим или сегодняшним дедлайном

### Фильтрация
- По статусу: все / активные / выполненные
- По приоритету: быстрые чипсы-фильтры под табами
- По тегу: клик по тегу в списке или по чипсу фильтров

### Планировщик-календарь
- Переключатель «Список / Планировщик» над фильтрами
- Месячный календарь с цветными точками задач на каждый день
- Клик по дате открывает панель с задачами на этот день
- Добавление задач непосредственно из панели дня с автоматической привязкой дедлайна

### Прочее
- Статистика: всего / активных / выполненных и прогресс-бар
- Задачи сохраняются в `localStorage` — не теряются при перезагрузке
- Адаптивная вёрстка для мобильных устройств

## Технологии

- HTML5, CSS3 (переменные, анимации, адаптив)
- Vanilla JavaScript — без фреймворков и зависимостей

## Запуск локально

Откройте файл `index.html` в любом браузере — никаких зависимостей не требуется.
